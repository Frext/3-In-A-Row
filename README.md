# 3-In-A-Row

[![Language](https://img.shields.io/badge/Language-Kotlin-purple.svg?style=flat&logo=kotlin)](https://kotlinlang.org/)
[![Type](https://img.shields.io/badge/Type-Console%20App-orange.svg?style=flat&logo=gnutelephony)](https://en.wikipedia.org/wiki/Console_application)

A minimalist, turn-based console game written in **Kotlin**. 

---

## 🎯 The Goal
Be the first player to align **3 dots in a row** (horizontally, vertically, or diagonally).


⚠️ **The Catch:** Every new dot you place *must* be adjacent to a dot already on the board!

---

## 🚀 Getting Started

1. **Clone the repository:**
```bash
   git clone [https://github.com/Frext/3-in-a-row.git](https://github.com/Frext/3-in-a-row.git)
   cd 3-in-a-row
```
2. **Run the game**
```bash
  ./gradlew run
```
