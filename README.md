# 3-In-A-Row

A minimalist, turn-based console game written in **Kotlin**. 

---

## 🎯 The Goal
Be the first player to align **3 dots in a row** (horizontally, vertically, or diagonally).


⚠️ **The Catch:** Every new dot you place *must* be adjacent to a dot already on the board!

---

## 🚀 Getting Started

1. **Clone the repository:**
```bash
   git clone [https://github.com/Frext/3-In-A-Row.git](https://github.com/Frext/3-In-A-Row.git)
   cd 3-In-A-Row
```
2. **Run the game**
```bash
  ./gradlew run
```

---

## 🎮 How to Play
* Players take turns entering coordinates into the console to place their dots.
* Remember to follow the adjacency rule!
* The game will automatically detect and announce the winner when a 3-in-a-row is achieved.
